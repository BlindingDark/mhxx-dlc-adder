#+TITLE: MHXX DLC 追加工具

在线使用：[[https://blindingdark.github.io/mhxx-dlc-adder/][打开工具页面]]

浏览器端工具，用于给《怪物猎人 XX》存档追加汉化 DLC 任务和特殊随从猫。全部处理都在本机浏览器完成，不上传存档。

* 功能

- 追加活动任务和联动任务
- 追加特殊随从猫到空槽
- 只写入空槽，不修改已有随从猫
- 可选择要追加猫的角色槽
- 可选维持等级：按所选角色槽分别继承该槽最高等级/经验
- 可选同时生成 =system_backup= 副本
- 全部处理在浏览器本地完成，不上传存档

* 使用

1. 使用 Checkpoint 备份存档。
2. 打开[[https://blindingdark.github.io/mhxx-dlc-adder/][工具页面]]，选择导出的 =system= 存档。
3. 选择角色槽和特殊随从猫。
4. 生成并下载新的 =system=。
5. 使用 Checkpoint 导回主机。

* 注意

- 实机使用请配合 Checkpoint。
- 保留原始存档备份。
- 目标槽不足时不会静默截断。
